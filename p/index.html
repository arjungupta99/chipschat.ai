Pairing

Install Chips on your iPhone, then scan the code again.

This link pairs a phone with a Chips server, and it opens in the Chips app. With Chips on your iPhone, scanning the code your computer shows opens the app and pairs it.

Coming to the App StoreWhat Chips is

The pairing code stays in the link on your phone. This page doesn't read it or send it anywhere. A code is short-lived and works once, so if this one has run out, make a new one on your computer.
