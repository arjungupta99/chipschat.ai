Each connector here puts a harness, or a whole family of agents, into Chips. A connector lives with its harness, not in Chips (ADR 0051). Chips names no harness in its own code; this page is where they are named.

How far each one gets is said in the conformance kit’s levels:

  • Talks: an agent in a room that answers.
  • Supervised: a thinking bubble, steps, approvals, cost and Stop.
  • Lives in Chips: the +, agents, copies, new agents, rooms followed, and Restart.
  • Managed from Chips: context files, model, heartbeat, context window, and the dial.

The “Checked” column says what each claim rests on. Kit is a chips conformance run against the fake Chips. Live is the connector in use on a real server, in the walks Chips is tested with. Declared is what the connector says it does and nothing has checked yet.

The cards a person picks from in Chips, when they bring an agent, are this page’s too: they are kept in the docs’ connectors.json, which a release of Chips carries, a checkout reads where it is, and the server hands its apps (CHIPS_CONNECTORS points it elsewhere, ADR 0171). Each card says what to run, with {link} where a join link goes, and can say a sentence to paste to the agent so it connects itself.

A bridge’s card is one line, chips connect <id> '{link}', which Chips shows as CHIPS_JOIN_LINK='<link>' chips connect <id> so the link stays off the command line (the command), and names its npm package and major: @chipschat/hermes@1, @chipschat/opencode@1, @chipschat/acp@1 (Claude Code and Codex) and @chipschat/openclaw@1. chips connect fetches the newest release of that major, checks it against the registry, and runs it on the Node Chips carries (ADR 0218). All four are on npm at major 1 (Apache-2.0), each published from its own repository.

In Chips for Mac, a bridge’s card asks where the harness runs. On this Mac, Connect runs the card’s line for you and ticks off its four steps, listed under What Connect does: getting the bridge, checking the harness, joining Chips, and keeping it running. Where the bridge stops, it says why and what to do, and Try again runs the same line with the same link. On another computer, and in a browser or on the phone, the card gives curl -fsSL https://chipschat.ai/install | CHIPS_JOIN_LINK='<link>' sh -s -- connect <id>, which installs Chips on that computer when it isn’t there. Every line a person runs themselves says Run in Terminal on its box (ADR 0257). The link goes in the environment, not among the command’s words, which anybody else on that computer can list. A card’s needs says what has to be running first: after “You need” on this Mac, and after “That computer needs” on every card. Each card also says where its link works: on the computer Chips runs on, for a link on its loopback address, or wherever that computer can reach Chips’s address (ADR 0247).

A card can say three more things about the agent itself (ADR 0288). program is the agent’s own command: Chips for Mac looks for it, puts what it finds first and marks it On this Mac. whose says who makes the agent and where what a person sends it goes, beside its way in, and terms is a link to its maker’s terms or licence.

A card can also carry start, the written steps for somebody with no agent yet (ADR 0290). The gallery then shows I don’t have one yet, which asks what they already have. answer is what they say (“I pay for Claude”) and suggest is what Chips says back. steps are the maker’s own lines, each a sentence with a line to run in Terminal or a page to open, which the person runs themselves before pressing Connect. One card’s none is the answer for somebody with none of the others, with first steps, such as making an account, before its own. The same steps are on chipschat.ai/setup.

Getting a connector on this page

Section titled “Getting a connector on this page”
  1. Run chips conformance custom --capabilities <what it declares> against it, and say what the report’s levels say.
  2. Each capability it declares is checked when the kit can see it, and said as declared when it can’t. A declared capability that fails its check fails the run (see Conformance).
  3. For an agent family, say which agents it was checked with, as the ACP bridge’s row does.
