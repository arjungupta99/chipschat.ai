Questions

Here are answers to the questions that come up most.

My phone can't reach Chips away from home.

Away from home, your phone needs the relay, which is off until you turn it on: in Chips, go to You, then Relay, or run chips up --reach relay. A phone you paired before learns about the relay the next time it connects, so you don't pair it again.

A browser on another computer won't pair.

A browser makes its key only on a secure address, which is localhost or an https address. Tailscale Serve gives Chips an https address that only your own devices can reach.

How do I update Chips?

Chips for Mac doesn't update itself yet: download it again, quit Chips, and replace the copy in Applications. With the install line, run it again, then chips up, which starts Chips again on the new release. The install guide has both.

How do I stop Chips?

chips down stops the login service that chips up started.

Where should the Mac app be when I open it?

In Applications. A copy opened where it was downloaded runs from a folder macOS throws away.
