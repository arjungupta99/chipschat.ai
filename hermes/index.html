Chat with your Hermes agents in Chips.

Chips connects to Hermes Agent's API server. Each Hermes profile is a Chips agent, and each space is a Hermes session.

Before you start, you need Hermes running with its API server on, and Chips on your Mac or server.

Hermes connects with one line.

In Chips, add an agent and pick Hermes. Chips makes a join link and gives you the whole line with the link in it.

On the Mac that runs Chips

In Chips for Mac, choose On this Mac. Connect runs the line for you and ticks off its four steps: getting the bridge, checking Hermes, joining Chips, and keeping it running.

$CHIPS_JOIN_LINK='<link>' chips connect hermes

On another computer

Where Hermes runs on another computer, run this line there. It installs Chips on that computer first when it isn't there yet.

$curl -fsSL https://chipschat.ai/install | CHIPS_JOIN_LINK='<link>' sh -s -- connect hermes

The bridge is @chipschat/hermes on npm, under Apache-2.0. chips connect fetches its newest release, checks it against the registry and runs it on the Node that Chips carries.

From Chips

In a space, you see it think and the steps it takes, you answer its approvals, you see what a run cost, and you can stop it. From Chips you can also:

  • Talk to each of its agents by name.
  • Open a new space for it from the + in Chips.
  • Make a new agent from Chips.
  • Fork an agent into a new space, where the copy remembers everything so far.
  • Pick each agent's model and effort.
  • Edit an agent's instructions.
  • See how full an agent's context is, and compact it to make room.
  • Restart it from Chips.

These are what the bridge says it does. What an agent does with them depends on Hermes and how you've set it up. The gallery says what was checked, and when.

Notes

Forking an agent

Hermes forks its own session. The copy joins a new space and remembers everything so far. From then on, the two remember separately, and the original doesn't hear what the copy is told.

Asking before commands

Hermes v0.20.6's API server doesn't ask before guarded commands (issue #98728 on Hermes's GitHub). Until that's fixed, only its MCP consent reaches Chips as a card.

Version checked

Hermes 0.22, on 16 and 17 October 2026.
