Set up

You can start using Chips even if you have no agent yet.

An agent is the AI that does the work, and Chips is where you talk to it. Each agent comes from its maker, so you install it and sign in with the maker's own tools. Chips connects to it once it's there.

1

Get Chips on your computer.

Download for Mac

On Linux or a Mac with no screen, install it with these two lines. On Windows, Chips runs in WSL: run them in a WSL terminal.

$curl -fsSL https://chipschat.ai/install | sh
$chips up
2

Choose the agent you'll use.

I pay for Claude

We'd suggest Claude Code, Anthropic's coding agent.

  1. Install Claude Code.

    $curl -fsSL https://claude.ai/install.sh | bash

  2. Sign in. Your browser opens with Anthropic's sign-in.

    $claude auth login

  3. Install the adapter Chips reaches Claude Code through. It needs npm, which comes with Node.js from nodejs.org.

    $npm install -g @agentclientprotocol/claude-agent-acp

Claude Code is made by Anthropic and has its own terms. What you send it goes to Anthropic. Its terms

I use ChatGPT

We'd suggest Codex, OpenAI's coding agent.

  1. Install Codex.

    $curl -fsSL https://chatgpt.com/codex/install.sh | sh

  2. Sign in with your ChatGPT account. Your browser opens with OpenAI's sign-in.

    $codex login

Codex is made by OpenAI and has its own terms. What you send it goes to OpenAI. Its terms

Neither of those

You'll need an account with one of the makers. We'd suggest a free ChatGPT account, which includes Codex.

  1. Make a ChatGPT account on OpenAI's site. OpenAI's free plan includes Codex.

    Open chatgpt.com

  2. Install Codex.

    $curl -fsSL https://chatgpt.com/codex/install.sh | sh

  3. Sign in with your ChatGPT account. Your browser opens with OpenAI's sign-in.

    $codex login

Codex is made by OpenAI and has its own terms. What you send it goes to OpenAI. Its terms

3

Connect it in Chips.

Open Chips, choose the agent and press Connect. When it says hello you can start talking to it, and Chips shows a QR code for your phone.
